 Pliny Inference
The Pliny Inference service enables seamless access to all the Synopsys
approved and hosted FOSS/finetuned GenAI models and Azure cloud models.
Pliny Inferencing Platform employs various built-in capabilities such as:
Autoscaling of model deployments based on number of concurrent users.
Providing secured inference endpoints for all SNPS hosted models.
Providing API token authenticated unified LLM endpoints.
Enforce guardrails and ratelimiting per user, model, API tokens.

Inference Pliny Model with cURL ​ 
pliny inference gateway docs <model> --type <type> 
Type can be [ chat | completion | embedding | rerank ] which can be chosen
from the "Types" column of the pliny inference gateway list-models 
command.
By default this command gives the curl command for the selected model on
terminal.
Run Command
 View Output
 pliny inference gateway docs snps-provider/llama-3-3-70b-instruct --type chat 
📄 Click to expand command output curl -X POST "https://snps-inference.internal.synopsys.com/api/llm/chat/completions" \ 
 -H 'Authorization: Bearer <YOUR-API-KEY>' \ 
 -H 'Content-Type: application/json' \ 
 -H 'X-TFY-METADATA: {}' \ 
 -H 'X-TFY-LOGGING-CONFIG: {"enabled": true}' \ 
 -d '{ 
 "model": "snps-provider/llama-3-3-70b-instruct", 
 "messages": [ 
 {"role": "system", "content": "You are an AI bot."}, 
 {"role": "user", "content": "Enter your prompt here"} 
 ], 
 "stream": false 
 }' 
warning
 The generated output contains your personal access tokens, so please do
not share the generated output to anyone.
 In case you have to share it, please mask your personal access tokens.
Save Pliny Model Inference in a file ​ 
pliny inference gateway docs <model> --type <type> --file <file_name> 
E.g. 
 pliny inference gateway docs snps-provider/llama-3-3-70b-instruct --type chat --file llama_3_3_70b_curl.sh 
Inference Pliny Model in any language ​ 
pliny inference gateway docs <model> --type <type> --language <language> 
It supports various languages like
 [ openai | langchain | stream | node | rest | curl | cohere ] .
Run Command
 View Output
 pliny inference gateway docs snps-provider/llama-3-3-70b-instruct --type chat --language openai
