# PlinyCode Desktop 0.1.3

- Fixed Improve prompt timing out on connections that require the operating system's certificate trust or proxy settings. The request now uses Electron's native networking, with certificate verification enabled.
- Timeout and cancellation now have distinct messages. Failed requests continue to preserve the draft.

**On 0.1.2:** choose **Check for updates**, **Download 0.1.3**, then **Install 0.1.3 and restart** when tasks have stopped. Projects, chats, settings and credentials are preserved.

Versions 0.1.0 and 0.1.1 need a manual installation of this release. See `INSTALL.md` for Windows and Ubuntu instructions. The preview installer remains unsigned.
