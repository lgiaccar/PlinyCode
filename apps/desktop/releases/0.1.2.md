# PlinyCode Desktop 0.1.2

- Desktop now checks automatically for new stable Desktop versions, with a manual **Check for updates** button and an option to disable automatic checks.
- Choose **Download**, then **Install and restart** from the sidebar. Downloads are integrity-checked; installation waits for tasks, background commands and PR operations to stop.
- Windows uses the per-user installer; AppImage updates replace the portable application, and DEB updates use the system package manager with administrator authentication when needed.
- Failed checks and corrupt downloads preserve the current installation and allow retry.

**Users on 0.1.0 or 0.1.1 must install 0.1.2 manually once to receive the updater.**
Close Desktop and run the new installer as the same user. Saved projects, chats,
settings and credentials are preserved. See `INSTALL.md` for all platforms.

The preview installer remains unsigned. The extension and CLI release channels are unchanged.
