# PlinyCode Desktop 0.1.5

- Fix upgrades of older local-only Git projects: projects with no saved worktree source now automatically select Local branch when no remotes exist. Explicit settings remain unchanged. This fixes the missing-origin failure that could persist after installing 0.1.4.
- Add Copy buttons for prompts and responses, native right-click copy/paste, and plain-text prompt rendering that preserves whitespace.
- Add Edit and restart to earlier prompts. Restart replaces the selected prompt and removes later turns from both the chat and model context. Files and external actions are not undone; stop running work and background commands first.
- Save pre-turn history snapshots and previous chat revisions. Restarted conversations retain their corrected history after reopening. Older prompts that cannot be located safely can be copied into a new chat or restarted from the first prompt.

On Desktop 0.1.2 or later, choose **Check for updates**, **Download 0.1.5**, then **Install 0.1.5 and restart**. For a previously failed local-only task, use **Edit and restart** on its original prompt. The preview installer remains unsigned.
