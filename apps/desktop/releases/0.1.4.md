# PlinyCode Desktop 0.1.4

- Local-only Git repositories can now run isolated tasks without an `origin` or another remote. Project settings offer **Worktree source → Local branch**, with the current local branch as the default base. New local-only projects select this automatically.
- Existing projects keep their chosen behavior. If a task failed because `origin` was missing, open project settings, choose **Local branch**, save and resend the prompt.
- Local worktrees use committed content. Staged, unstaged and untracked changes remain in the original folder. Repositories with no commits receive a clear message explaining that a first commit is needed for a worktree.
- Ordinary folders work without Git initialization, remotes or fetching; tasks sharing the folder run one at a time. Git-only project settings are hidden for these folders.
- Missing remote configuration now produces an actionable message instead of an ambiguous Git access error. Remote-based worktrees still fetch unless the user explicitly chooses the cached revision.

On Desktop 0.1.2 or later, choose **Check for updates**, **Download 0.1.4**, then **Install 0.1.4 and restart**. Earlier versions require a manual installation. Projects, chats, settings and credentials are preserved. The preview installer remains unsigned.
