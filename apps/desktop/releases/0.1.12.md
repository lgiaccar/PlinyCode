# PlinyCode Desktop 0.1.12

- Create a project with a name and one or more folders before starting its first chat.
- Rename projects and add or remove folders in Project settings, including the first folder. Existing chats retain their original folders and repository settings; folder changes apply to new chats.
- Delete a project while keeping its chats and drafts under **Archived chats** by default. Continue an archived chat or restore its project whenever needed.
- Select **Also delete saved chats** to permanently remove the project's chats, drafts and stored chat history. Project folders, files and Git worktrees remain untouched with either choice.

Stop active tasks and background commands before changing or deleting a project. Multi-folder chats work directly across the selected folders; single-folder Git projects retain isolated worktrees.

Install the Windows EXE, Ubuntu DEB or AppImage from this release, or use Desktop's update controls. Existing projects, chats and settings are preserved during the upgrade. The VS Code extension and CLI versions are unchanged.
