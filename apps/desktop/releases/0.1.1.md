# PlinyCode Desktop 0.1.1

- Added **Improve prompt** beside Send: rewrite a draft for clarity with a free model, then review it before sending.
- Added **Undo improvement** to restore the original draft.
- Protected drafts against failed requests, timeouts, edits and chat changes during a rewrite.
- Published Windows x64 one-click installer and Ubuntu x64 DEB/AppImage downloads with SHA-256 checksums.

This is a desktop preview. The installer is unsigned. Updates are manual: close Desktop
and install the new package as the same user; saved conversations and settings are retained.
Desktop 0.1.0 does not automatically update to this version. See the attached `INSTALL.md`.

The VS Code extension and CLI versions are unchanged.
