# PlinyCode Desktop 0.1.6

- Keep separate unsent drafts when switching chats. New chats start empty, delayed attachments stay with their original chat, and sending a message no longer clears a newer edit. Unsent drafts are retained while the app is open.
- Prevent overlapping writes when tasks share a folder or an existing worktree, including projects at filesystem roots. Stopping a background command keeps its folder reserved until the process exits.
- Prevent PR creation from overlapping a prompt restart or another task operation.
- Fix offline cached worktree startup in repositories created with Git init and a remote, and refresh the cached default branch when the remote default changes.

On Desktop 0.1.2 or later, choose **Check for updates**, **Download 0.1.6**, then **Install 0.1.6 and restart** while idle. Earlier versions require a manual installation. Projects, conversations, settings and credentials are preserved. The preview installer remains unsigned.
