# PlinyCode Desktop 0.1.10

- Browse up to three suggested next prompts with Left/Right. Tab accepts the selected prompt into your draft; Enter sends it.
- Use Suggest prompt in an empty composer to generate or retry suggestions, and Generate alternatives to request fresh choices. The same button still improves a typed draft.
- See when generation is running, failed, or found no useful follow-up. Failed requests no longer remain cached, and late replies never replace your edits.

Install the Windows EXE, Ubuntu DEB or AppImage from this release, or use Desktop's update controls. Existing projects, chats and settings are preserved. No configuration changes are required.
