# PlinyCode Desktop 0.1.9

## One project, several folders

- Select several folders when adding a project, or open **Project settings → Add folders…**, save, and start a new chat.
- One chat can read, search, edit and run commands across its selected folders. The first folder is the default command directory.
- Give projects a name, open any chat folder from the header, and review Git changes from each folder together.
- Chats with overlapping folders wait for each other, including while background commands run.
- Existing chats retain their original folders after project changes and app restarts. Removing a folder from the project list never deletes its files.

Multi-folder chats edit the selected folders directly. Isolated worktrees and the built-in Create PR button remain available for single-folder Git projects.

## Install or update

In Desktop 0.1.2 or newer, use **Check for updates → Download → Install and restart** while tasks are idle. Earlier versions need one manual installation.

Download the Windows x64 installer, Ubuntu x64 DEB, or portable AppImage below. Verify the download against **SHA256SUMS** and follow **INSTALL.md**. Saved conversations and credentials are preserved. This preview is unsigned.

The VS Code extension and CLI have separate release channels.
