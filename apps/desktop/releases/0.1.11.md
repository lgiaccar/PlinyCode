# PlinyCode Desktop 0.1.11

- Set MCP request timeouts above two minutes for long meshing and other tool operations. The settings arrows and save validation now accept 1–3600 seconds, matching the engine's supported range.
- Typed values such as 1000 seconds (16 minutes 40 seconds) save correctly and remain unchanged after restarting Desktop.

After updating, open **Settings → MCP servers**, edit your server, enter the timeout in seconds, and save. Changes apply to the next run; existing saved timeouts are preserved. The default remains 30 seconds, and server or network timeouts can still end a request earlier.

Install the Windows EXE, Ubuntu DEB or AppImage from this release, or use Desktop's update controls. Existing projects, chats and settings are preserved. The VS Code extension and CLI versions are unchanged.
