# PlinyCode CLI 0.1.0

PlinyCode is now available as a portable terminal and pipeline CLI for Windows x64
and Linux x64. The included runtime means Node, Bun and VS Code are not required.
A Pliny API key and access to the Synopsys Pliny gateway are required for model calls.

- Interactive chat with follow-up messages, tool approvals and transcript export.
- FreeAuto by default, with optional concrete model selection.
- Pipeline prompts, text files and stdin; JSON Schema output validation and reports.
- MCP stdio, HTTP and SSE connections, with explicit approval for unattended tools.
- Windows encrypted credentials and Linux Secret Service support; environment secret injection for CI.

Download the Windows `.zip` or Linux `.tar.gz` below. Verify it against `SHA256SUMS`,
extract the whole folder, then run `plinycode doctor`, `plinycode auth login` and
`plinycode chat` (`.\plinycode.cmd` in PowerShell inside the extracted folder).

[Complete installation and pipeline instructions](https://github.com/lgiaccar/PlinyCode/blob/cli-v0.1.0/docs/cli-install.md)
are also attached as `INSTALL.md` and included in each package.

Windows and Ubuntu portable packages are tested after download without a source
checkout or separately installed Node/Bun. Tests use local gateway and MCP fixtures;
your gateway, network and external tools must be configured separately.

This release does not include macOS/ARM64 builds, a YAML job parser, an API server,
or persistent chat resume. It does not change the VS Code/Cursor extension release
or trigger editor updates.
