# PlinyCode CLI 0.1.1

- Automatically discover skills and custom agents from the same workspace folders
  used by the PlinyCode extension, or select folders with `--skills-dir` and
  `--agents-dir` (both repeatable).
- Inspect loaded definitions with `plinycode skills` and `plinycode agents`,
  including `--json`, without a Pliny API key.
- Select a custom lead with `--agent`, delegate to named agents, or use generic
  sub-agents. FreeAuto remains the default and keeps delegation on free models.
- Preserve child tool approvals, serialize simultaneous approval prompts and
  enforce custom agents' skill restrictions through the shared engine.
- Expand source, packaged and downloaded-package tests for discovery, skills,
  delegation, model restrictions and cancellation.

Upgrade by extracting the new Windows ZIP or Linux tar.gz into a new directory
and updating PATH. Keep the entire folder, including `runtime/`. Existing secure
CLI credentials continue to work. No server or persistent session resume is added.

Skills provide instructions; scripts and MCP servers still require their own
dependencies. Unattended delegation requires `--allow-tools`. See the installation
guide and tester PDF attached to this release for setup and acceptance tests.
