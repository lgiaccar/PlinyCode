# PlinyCode CLI 0.1.2

- Add `plinycode --version` and explicit Windows/Linux self-update commands:
  `update --check`, `update`, `update --version <version>` and `update --rollback`.
- Discover stable CLI releases independently of extension/Desktop releases.
- Verify archive and file checksums, extract safely and test startup before switching
  the active version. Keep the previous version for verified offline rollback.
- Preserve the launcher, PATH, credentials, custom skills/agents and running tasks.
  Serialize updates and recover locks left by terminated updater processes.
- Add optional daily chat-only notifications with `PLINYCODE_UPDATE_NOTIFY=1`.
  Pipeline runs never check for or install updates automatically.
- Test packaged upgrades, rollback and failed updates on Windows and Ubuntu 22.04/24.04.
  Retain the 0.1.1 skill discovery, custom agents and delegation features.

Users on 0.1.0/0.1.1 must download and extract 0.1.2 manually once. Keep the whole
folder in a user-writable location and update PATH. Later releases can be installed
with `plinycode update`. The installer guide and updated tester PDF are attached.
