# PlinyCode CLI

Minimal interactive chat and pipeline-friendly execution using the Pliny engine.
See the [CLI guide](../../docs/cli.md) for installation, approvals, MCP servers,
structured output, skills, custom agents and delegation examples. Use `skills`
and `agents` to inspect workspace discovery, `--skills-dir` / `--agents-dir` for
custom folders, and `--agent` to select a lead agent. There is no YAML job parser
or local API server.
